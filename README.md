# 📱 Threads Clone – React Native  
A fully functional Threads clone built with React Native, inspired by the official Threads app. This project showcases my ability to develop scalable, high-performance mobile applications with modern UI/UX and robust backend integration.  

## 🚀 Features  
✅ User authentication (Sign up & Login)  
✅ Create, like, and comment on posts  
✅ Follow/unfollow users  
✅ Real-time updates  
✅ Smooth UI/UX animations  
✅ Dark mode support  

## 🛠️ Tech Stack  
- **Frontend:** React Native, Expo  
- **State Management:** Redux Toolkit  
- **Backend:** Firebase (Auth, Firestore, Storage)  
- **Styling:** Tailwind CSS for React Native

## 📂 Installation & Setup  
Clone the repository:  
```sh
git clone https://github.com/betomoedano/React-Native-Threads-Clone.git
cd React-Native-Threads-Clone
```
Install dependencies:  
```sh
npm install
```
Start the app:  
```sh
npx expo start
```
